# 病例情境插畫

V1.6 第一階段使用 8 份病例圖；第二、三階段沿用 12 份既有病例圖。共用圖片採相同檔名，均存於 `public/art/cases/`。插畫以 800 × 1000（4:5）直式構圖為主，不裁切或拉伸；病患身體圖與感受文字仍是主要線索。

目前首頁兩張、角色三張、病例十五張，共 20 張 WebP 圖片。V1.6 已補入 `covid.webp`、`bacterial_gastro.webp`、`functional_dyspepsia.webp`，並替換 `allergy.webp`。

重新上傳圖片後，請確認其檔名與病例 ID 一致。修改或新增圖片檔案時，若有新增路徑，請同步更新 `tests/fixtures/art-manifest.json` 的路徑與預期尺寸；**替換同名圖片不需更新任何舊檔 SHA-256**。部署時會以最新儲存庫圖片作為基準，逐張比對 GitHub Pages 實際圖片的 SHA-256，避免部署內容與原始檔不一致。

圖片缺漏或載入失敗時顯示「劇情圖片」。不要讓情境插畫或替代文字直接揭露疾病名稱或正確答案。
