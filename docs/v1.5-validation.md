# V1.5：完整美術及介面整合

## 素材與畫面

- 使用附件 `medical_challenge_art_v1_5.zip` 中的17張原始 WebP，路徑直接位於 `public/art/`，沒有多套一層目錄。各檔案 SHA-256 與附件 manifest 一致，沒有替換或重畫圖片。
- 首頁使用等比例文字 Logo 及16:9主視覺；H1「醫問到底！」保留給無障礙閱讀，Logo 失敗時顯示文字。橫向平板與桌面的三個入口都在第一屏範圍內。
- 三張角色卡採一致圖框、角色標題、簡短任務與指定 CTA；整卡只有一個原生 button，沒有巢狀互動，支援鍵盤、觸控、焦點與按壓回饋。
- 病人端十二病例依 ID 載入800×1000圖片，使用4:5框及 contain，不拉伸、裁切。桌面與人體圖並排；較窄平板與手機改上下配置，情境圖限制尺寸，人體圖、連接線及感受文字保留。
- 缺圖保留「劇情圖片」；實際載入錯誤也切換佔位。角色與主視覺失敗時有文字後備，仍可進入角色。
- 補齊十二疾病與28症狀的小型線條 SVG，沒有把情境插畫縮成症狀圖示。
- 指定四段可見文字移除，精簡學生端同步、版本與內部運作說明；規則、操作提示、未知資訊處理及教師保存警示保留。
- 頁尾兩行置中顯示指定安全提醒、V1.5及教師署名；版本取自 package.json。

## 正式部署檢查

沿用既有 Pages base 與 main 自動部署，增加部署後17個公開圖片 URL 的 HTTP、Content-Type 及 SHA-256 檢查。任何一張缺圖、回傳非圖片或內容錯誤都會讓工作流程失敗，完整結果寫入 Actions Summary。

目前雲端環境對 Pages 網域的直接連線回傳代理403，因此不以此環境的直接瀏覽冒充上線驗證；正式網址內容檢查由 GitHub Actions 部署後執行，以本次 main 對應工作流程結果為準。本機正式建置預覽的17個網址與雜湊已通過同一支腳本。
