# 醫問到底！V2.0｜P0 定稿後資料化規格

## 版本與隔離
- 四種疾病前後測共 80 題已由教學端定稿。
- `main` 仍是 V1.6 正式版；V2 程式在 `v2-development` 分支進行。
- 禁止以自動題庫生成器改寫已核准題目內容；只允許結構化轉錄與忠實校對。
- 80 題與 320 個選項已轉錄至 `src/v2/assessment/data/`，並保留每題原定的選項位置、+2／+1／0／−1 分數；題庫結構已加入自動測試。
- 目前仍屬開發分支，未將 V2 接入學生遊戲介面，亦未發布 V2。

## 每個疾病的固定結構
```js
{
  id: "cold",
  scenario: "同一位虛構病患的固定病情；前後測共用",
  pre: [
    {
      id: "P01",
      axis: "symptoms",
      prompt: "醫師問：……",
      options: [
        {id:"A",text:"……",score:1,reason:"教師用判分依據"},
        {id:"B",text:"……",score:-1,reason:"教師用判分依據"},
        {id:"C",text:"……",score:2,reason:"教師用判分依據"},
        {id:"D",text:"……",score:0,reason:"教師用判分依據"}
      ]
    }
  ],
  post: [/* T01 至 T10；同一案例，不同問題 */]
}
```

## 固定驗證規則
- 四種疾病：一般感冒、過敏性鼻炎、急性腸胃炎、緊縮型頭痛。
- 每種前測 10 題，後測 10 題；每階段共五軸，每軸兩題。
- 五軸為：哪裡不舒服、何時開始、過敏情況、吃過什麼藥、自己的需求。
- 每題 4 選 1；後台必須各有且只有一個 +2、+1、0、−1；前台不顯示分數或判分理由。
- 0 分：合理不知道；−1 分：已有資訊卻說不知道，或陳述與病例矛盾。
- 分數依原始選項 ID 計算，不得用畫面選項位置判分。
- 雷達圖每軸 0–4；原始負分須分開保留。
- 前後測只比較**同一種疾病、同一份基本情境**，不能交叉比較不同疾病。
- 學生選的是「最接近自己會說的話」，量測的是模擬情境中的自陳表達選擇，不可直接宣稱是臨床溝通能力。
- 只記錄所選的模擬疾病，不需蒐集實際個人病史或健康資料。

## 資料驗收門檻
- 每種疾病完成 20 題資料化後，以測試確認題數、各向度題數、四種分數及題目 ID。
- 逐項校對題幹、四選項、分數與 P0 定稿一致；只有全部通過才能接入前後測 UI。
- 目前舊版三階段維持不變；第三階段在 V2 流程開發時才移除，不於資料化階段刪除。

## 題庫檔案
- `cold.js`：一般感冒前後測各10題
- `allergy.js`：過敏性鼻炎前後測各10題
- `gastro.js`：急性腸胃炎前後測各10題
- `tension-headache.js`：緊縮型頭痛前後測各10題
- `index.js`：統一題庫入口與全部驗證
- `make-case.js`：加入固定選項ID與後台判分依據（不改寫題目文字）

題庫文字仍應在正式介面發布前，與教師定稿文本逐字複核；程式測試主要驗證結構、數量、計分與前後測一致性，不能取代人工校稿。
